# 文件格式与分割器

`zwraw-v1` 文件由 64 字节固定头和交错 `float32` 的小端电压值构成：

| 偏移 | 类型 | 说明 |
|--:|--|--|
| 0 | char[8] | `ZWRAW01\0` |
| 8 | uint32 | 版本 `1` |
| 12 | uint32 | 采集通道位掩码（CH1=1、CH2=2、CH3=4、CH4=8） |
| 16 | uint32 | 有效通道数 |
| 20 | uint32 | 采样类型 `1` = float32 V |
| 24 | float64 | 实际采样率，Hz |
| 32 | uint64 | 全会话起始样本索引 |
| 40 | uint64 | 本分段的采样帧数 |
| 48 | uint64 | 采集会话起始 Unix 毫秒 |
| 56 | uint8[8] | 保留 |

每帧代表同时采集的全部已记录通道，通道顺序按 CH1→CH4 排列。`metadata.json` 存储用户自定义通道名、请求/实际采样率、分段列表及来源连续性说明，完整退出后写入。意外断电、磁盘写入失败时，文件可能没有完整头部/元信息，现有分割器会拒绝不完整分段；不假称数据完好。

## 导出规则

1. 选择输入单个 `.zwraw` 或包含一组分段的会话目录。
2. 选择需要的物理通道、起始样本、样本总数（`0` 代表剩余全部）、每个 CSV 最大样本数（256～200000）。
3. 输出目录写入 `export_0001.csv`、`export_0002.csv` 等，内部按照 `zhuru-wave-v1` 生成 `X1/Y1/X2/Y2` 固定列名，用户自定义通道名保存在会话 `metadata.json`，避免现有读入器拒绝自定义列名。
4. 导出 `amplitude_unit` 为 `V` 或 `mV`；`synchronized=true` 只表示**同一批采集帧内的通道对齐**，不能证明旧 DLL 轮询窗口之间无丢采样。

分割器会检查输入分段尺寸、统一采样率和通道配置、起止索引无缺口。若导出目标目录已有 `export_*.csv`，请使用新目录，避免与旧导出混淆。
